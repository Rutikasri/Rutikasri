# 🧠 Featured Projects

## 🔹 GIAN Multi-Source RAG Assistant

A multi-source **Retrieval-Augmented Generation** system designed to retrieve information from multiple knowledge sources and generate source-grounded answers.

**Tech:** Python · RAG · ChromaDB · Sentence Transformers · Groq · LLaMA · Streamlit

**Highlights**

* Indexed **703 records** into ChromaDB
* Implemented semantic retrieval and fallback strategies
* Used embedding-based search for relevant information retrieval
* Generated responses using **LLaMA 3.3 70B through Groq**
* Added source attribution and hallucination checks
* Implemented entity and relationship linking across sources

## 🔹 DocuParse — Multimodal Document AI

An end-to-end **OCR + Machine Learning + Document AI** pipeline for extracting structured information from receipts.

**Tech:** Python · PyTorch · Hugging Face · OCR · LayoutLMv3 · CORD · Flask

**Pipeline**

`Document → OCR → Text + Bounding Boxes → LayoutLMv3 → Information Extraction → Structured Data`

**Highlights**

* Fine-tuned LayoutLMv3 for receipt information extraction
* Processed OCR text and spatial bounding-box information
* Trained using the CORD dataset
* Extracted fields such as vendor, date and total amount
* Built an inference pipeline and web application
